# Тёмная тема «Графит» для sinay.ua — как внедрить

Кнопка в шапке переключает тему: светлая → тёмная → снова стандартная светлая.
Выбор запоминается и сразу применяется **во всех открытых вкладках** сайта (без перезагрузки).

## Файлы

| Файл | Что это | Куда |
|---|---|---|
| `theme-dark.css` | Стили тёмной темы и кнопки | Загрузить на сервер в `/theme-toggle/` |
| `theme-toggle.js` | Логика переключения и синхронизации вкладок | Загрузить на сервер в `/theme-toggle/` |
| `snippet-head.html` | Скрипт против «мигания» и подключение CSS | Вставить в `<head>` общего шаблона, повыше |
| `snippet-button.html` | Разметка кнопки | В шапку: внутри `.header_right_wrap`, сразу перед `.languages` (между телефоном и языком) |
| `snippet-body-end.html` | Подключение JS | Перед `</body>` |

**Важно про языки.** Все три сниппета вставляются в общие шаблоны (`<head>`, шапка, конец `<body>`),
которые используются и для русской, и для украинской версии сайта. Если вставить только в один язык,
при переключении RU/UA кнопка пропадёт. Подписи кнопки скрипт сам ставит на языке страницы
(по `<html lang="...">`), а выбранная тема при смене языка сохраняется.

Если файлы лежат не в `/theme-toggle/`, поправьте пути в `snippet-head.html` и `snippet-body-end.html`.

## Как это работает

- Тёмная тема включается атрибутом `data-theme="dark"` на теге `<html>`. Все правила в
  `theme-dark.css` начинаются с `html[data-theme="dark"]`, поэтому светлая тема не меняется.
- Выбор хранится в `localStorage` под ключом `sinay-theme`. Для светлой темы запись удаляется.
- Синхронизация вкладок: когда меняется `localStorage`, браузер отправляет событие `storage`
  во все остальные вкладки сайта, и они применяют ту же тему.
- Скрипт в `<head>` включает тему ещё до отрисовки страницы, поэтому светлая не мелькает.
- jQuery и другие библиотеки не нужны.

## Если поменяется CSS сайта

`theme-dark.css` собран автоматически из текущего CSS сайта: все цвета заменены на цвета палитры
(переменные `--bg`, `--surface`, `--text` и т.д. в начале файла). Мелкие правки можно делать прямо
в файле. Если дизайн сайта сильно изменится, тёмную тему лучше пересобрать генератором
(он хранится у автора темы).

## Проверено на демо

- Кнопка переключает тему туда и обратно, иконка меняется (луна ↔ солнце).
- Во второй открытой вкладке тема меняется сразу, без перезагрузки.
- После перезагрузки страницы тема сохраняется.
- Мобильная шапка: кнопка подогнана по размеру, иконка каталога видна.
- Смена языка RU ↔ UA: кнопка на месте, тема сохраняется.
- Страницы: главная (RU и UA), каталог, карточка товара, пустая корзина, контакты.

## Что проверить после внедрения

Тема собрана из общего файла стилей `main.min.css`, поэтому работает на всех страницах,
которые его используют. Отдельно стоит посмотреть то, что не удалось проверить на демо:

- Оформление заказа с товарами в корзине и поле телефона с выбором страны (`intlTelInput.css`).
- Галерея фото товара во всплывающем окне (`fancybox.min.css`).
- Окна входа/регистрации и личный кабинет.
- Тексты из админки, где цвет задан вручную (`style="color:#000"`): такой текст останется тёмным.
  Его нужно поправить в самом тексте или добавить правило в `theme-dark.css`.
