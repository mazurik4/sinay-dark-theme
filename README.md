# Sinay.ua — тёмная тема «Графит» (демо)

Демо-просмотр тёмной темы для [sinay.ua](https://sinay.ua) с кнопкой переключения в шапке
(между кнопкой телефона и выбором языка).

**Открыть демо:** `demo/index.html` (на GitHub Pages — ссылка в описании репозитория).

## Что можно проверить в демо

- Кнопка в шапке: первое нажатие включает тёмную тему, второе возвращает стандартную.
- Тема меняется сразу во всех открытых вкладках и сохраняется после перезагрузки.
- Переключение RU/UA — тема остаётся, подписи кнопки на языке страницы.
- Страницы: главная, каталог, товар, корзина, контакты (RU и UA).

Демо — это сохранённые копии страниц sinay.ua с подключённой темой. Картинки и стили берутся
с живого сайта; корзина, поиск и формы в демо не работают. Страницы закрыты от индексации.

## Структура

| Папка | Что внутри |
|---|---|
| `theme-toggle/` | Файлы для внедрения на сайт и инструкция для разработчика (`README.md`) |
| `demo/` | Демо-страницы |
| `tools/build_theme.py` | Генератор `theme-dark.css` и демо из CSS сайта |
| `site/` | Исходные стили и страницы sinay.ua, из которых собирается тема |

Пересборка после изменения стилей или палитры:

```
python3 tools/build_theme.py
```
